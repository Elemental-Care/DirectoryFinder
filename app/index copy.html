How to Use:
Option 1 (Easiest): Just open this file in your browser with "Use CORS Proxy" checked
Option 2: Run a local server to avoid CORS issues:
• Python: python -m http.server 8000 then visit http://localhost:8000
• Node.js: npx http-server then visit http://localhost:8080
• PHP: php -S localhost:8000 then visit http://localhost:8000
Standards & APIs:
• FHIR® 4.0.1 (HL7® Fast Healthcare Interoperability Resources)
• Da Vinci PDex Plan-Net Implementation Guide v1.0.0
• CMS NPPES National Provider Database
• BCBS/HCSC Provider Directory (FHIR)
• Cigna Provider Directory (FHIR, no authentication required)
• Aetna Provider Directory (FHIR with OAuth 2.0 Client Credentials)
Built with HTML, CSS, and JavaScript • No installation required • Works on any OS
